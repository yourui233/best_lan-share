# 已修复的问题

按版本记录。用法、选项与安全须知见 [README](../README.md)。

## v0.3.0-beta

### 新功能

- **待上传列表 + 上传前设置** —— 选好文件不再直接上传，先进列表：每个文件都能改文件名、选可见范围、
  勾加密，确认后再统一上传
- **文件设置（⚙）** —— 自己上传过的文件可以重命名、改可见范围、查看/更换提取码，还能就地加密
- **可见范围** —— 「仅自己可见」的文件对别人完全不存在（列表里没有、`/f/` 直链 404），只有上传者的
  浏览器、服务器本机、以及兑换过提取码的设备能看到
- **提取码** —— 私有文件由服务端生成 6 位码（去掉了 `0`/`O`/`1`/`I`/`L`），在页面右上角兑换；
  通行证是 HMAC 签名的 cookie，7 天有效
- **浏览器端端到端加密** —— ChaCha20-Poly1305 + PBKDF2-SHA256，分块加密、块号绑进 nonce 和 AAD；
  密码不出浏览器，磁盘上是随机文件名 + 密文，下载时逐块拉取并在浏览器里解密
- **给已上传的文件就地加密** —— ⚙ 里一键：整份下载 → 浏览器里加密 → 上传密文 → 删原件（先传后删，
  中途断了最多多留一份）

### 顺带修掉的

- 只读模式漏挡 `PATCH /f/<rel>`：新增这个接口时忘了加进 `isWrite()`，开了只读仍然能重命名
- 重名上传时显示名没跟着 `uniqueIn` 的 `" (2)"` 走，两个不同的文件会在列表里同名
- `docs/technical*.md` 里"`DELETE /t/<id>` 不校验归属"的说明早就过时了（v0.2.1 已修），一并删掉
